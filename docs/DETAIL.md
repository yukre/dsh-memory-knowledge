# 记忆知识库

只记想明白的结论。纯 Markdown 文件、文件夹分类、关系图串联；每晚由 DSH 自己的 agent 整理对话；你手改的文件受保护，并被当作纠正处理；回答用到记忆时附可点击的来源。

## 怎么用

- **日常对话**：不用做任何事。问到记忆库里的内容时，agent 会先查记忆；用上了会在回答末尾附「参考：」链接。
- **要它记住**：直接说"记住…… / 以后都…… / 别再……"。
- **发现记错了**：直接说"这条不对 / 过时了 / 忘掉它"，它会标争议或作废。
- **自己改**：直接编辑记忆文件夹里的 Markdown。改了什么会被记录下来，夜里整理时优先处理，机器不会把你的改动改回去。
- **左侧「记忆知识库」**：看状态、立即整理、导入资料、看改动和撤销、改设置。

## 限制

- 新对话里的结论要等夜间整理后才进入记忆（明确要求"记住"的除外）。
- "先查记忆再上网"是提示词约束，模型偶尔会不遵守。
- 记得好不好取决于整理用的模型；门禁只保证：依据真实存在、不照抄原文、作废的不会复活、你的修改不会被覆盖。
